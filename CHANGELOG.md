# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project follows [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-04

### Added

- Centralized design tokens for colors, typography, spacing, radii, shadows, layout, and motion.
- Typed reusable SVG icon component and centralized UI configuration.
- Light and dark themes with the selected theme persisted in the browser.
- Icons for the main navigation and logout action.

### Changed

- Modernized authentication pages, forms, buttons, cards, feedback messages, progress bars, and application navigation.
- Improved visual hierarchy, focus states, hover states, and reduced-motion support.
- Improved responsive behavior and mobile navigation.
- Updated the project brand subtitle from an academic label to a product-oriented workspace label.

## [1.0.0] - 2026-10-28

### Added

- Initial bachelor's thesis release.
- User registration and JWT-based authentication.
- Project creation, editing, deletion, membership invitations, and invitation responses.
- Task creation, assignment, progress tracking, comments, file attachments, and link attachments.
- User dashboard with project, task, invitation, and comment information.
- React and TypeScript frontend.
- Node.js, Express, and TypeScript REST API.
- MySQL relational database with validation, authorization checks, and test data.
